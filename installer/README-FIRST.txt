VOQORA EARLY-ACCESS INSTALL
============================

1. Drag Voqora.app to Applications.
2. Eject this disk image.
3. Open Voqora from Applications.

This early-access build is not yet Apple-notarized. If macOS blocks the first
launch, go to System Settings > Privacy & Security and choose Open Anyway for
Voqora, then open it again.

If that option is missing, use OPTIONAL-OPEN-VOQORA.command only after you
have confirmed this DMG came from the official Voqora GitHub release. It clears
the quarantine marker from /Applications/Voqora.app only, then opens that app.
It does not install Voqora, change any global macOS setting, or remove another
application.

Voqora is validating product fit during this early-access phase. Developer ID
signing and Apple notarization are planned for a later distribution channel.

Official release page:
https://github.com/himudigonda/Voqora/releases/latest
