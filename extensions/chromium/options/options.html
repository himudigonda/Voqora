Voqora for Chrome and Edge

Read web pages aloud with the Voqora app on this Mac.

Connection

The port shown in Voqora. The default is 51851.

Turn on the local API in Voqora

  1. Open Voqora and choose Preferences -> Integrations.
  2. Turn on Local API.
  3. Copy the port and the API key into the fields above, then choose Test Connection.

Learn more in the Voqora user guide

Privacy

The extension sends the text you choose only to Voqora at 127.0.0.1 on this Mac. Nothing goes to the internet. Your API key stays in this browser's extension storage.
